# 🤖 Machine Learning — From Scratch + Scikit-Learn

This repository documents my deep-dive into **Machine Learning algorithms**, where I implement every algorithm **from scratch in Python** first — focusing entirely on building the *intuition* of how the model actually works and the *math* behind it — before using **Scikit-Learn** for comparison and practical application.

My goal isn't just to use an algorithm, but to deeply understand *why* it works the way it does.

Part of my larger [Data Science & ML Journey](https://github.com/Itz-Me-Sumit/Data-Science).

---

# 🧠 What's Inside

For every algorithm below, the repo includes:
* **Scratch implementation** — full math derivation + Python code, no shortcuts
* **Scikit-Learn implementation** — practical/library-based version for comparison
* **Intuition-first notes** — what problem it solves, why the math works, when to use it
